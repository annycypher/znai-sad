<a id="статьи"></a>
## 1. Статьи (блог)

**Где:** админка → **Записи → Добавить запись**.

1. Заполните **Заголовок**.
2. В блоках выберите паттерн: кнопка **«+»** → вкладка **«Образцы» (Patterns)** → категория **«Сад знаний»** → **«Гайд по растению»**. Подставится готовая структура: вступление → фото → разделы H2 → чек-лист → FAQ. Замените текст заготовки на свой.
3. **Фото записи** (обложка): панель справа → **Запись → Изображение записи → Задать**. Без обложки карточка статьи выйдет без картинки — это нормально.
4. Выберите **Рубрику** (справа → Рубрики). Для обычных статей — любая, кроме «Рецепты».
5. **Опубликовать**.

**Где появится:** последние 2 статьи — в блоке **«Блог и советы»** на главной; все статьи — на странице «Все статьи» (кнопка в том же блоке).

**Как задать страницу «Все статьи»:** админка → **Настройки → Чтение** → «На главной отображать» → поставьте «Статическую страницу» (Главная) и в поле **«Страница записей»** выберите страницу «Статьи». Тогда кнопка «Все статьи» ведёт на неё.

<a id="рецепты"></a>
## 2. Рецепты

Рецепты — это обычные **записи** в отдельной рубрике «Рецепты», а не отдельный раздел.

1. Админка → **Записи → Добавить запись**.
2. Паттерн **«Рецепт»** («+» → Образцы → «Сад знаний»): состав → шаги → совет.
3. В блоке справа **Рубрики** отметьте **«Рецепты»**.
4. Опубликуйте.

**Где появится:** в архиве рубрики «Рецепты» — `http://sadznaniy.local/category/retsepty/`.
Чтобы этот раздел был в меню: **Внешний вид → Меню →** добавьте в меню пункт **«Рубрики → Рецепты»**.

<a id="события"></a>
## 3. События календаря

**Где:** админка → **События → Добавить событие**.

1. **Заголовок** — что делать (например, «Подкормка гортензий азотом»).
2. Текст — подробности (необязательно).
3. Панель справа → блок **«Дата и регион»**:
   - **Дата начала** — обязательна (по ней строится календарь и сортировка);
   - **Дата окончания** — необязательно (тогда срок покажется как «1 июня — 10 июня»);
   - **Регион** — Юг / Средняя полоса / Урал / Сибирь / Дальний Восток / Все регионы.
4. Опубликуйте.

**Где появится:** блок **«Календарь работ»** на главной — 3 ближайших события (по дате начала).
Прошедшие события скрываются автоматически. Кнопка «Весь календарь» ведёт на `http://sadznaniy.local/sobytiya/`.

**Список событий** (админка → События) показывает колонки **Дата** и **Регион**, по умолчанию сортирует по дате (ближайшие сверху). Щёлкните «Дата», чтобы изменить порядок.

<a id="растения"></a>
## 4. Растения

**Где:** админка → **Растения → Добавить растение**.

1. **Заголовок** — название (например, «Гортензия метельчатая»).
2. Текст — описание, посадка, уход (можно воспользоваться паттерном **«Гайд по растению»**).
3. **Фото растения** (обложка): справа → **Изображение записи**.
4. **Раздел** и **Тип** (справа или в блоке «Раздел»/«Тип») — см. пункт 5.
5. Блок **«Параметры выращивания»**: свет, полив, кислотность pH (от/до), почва.
6. Блок **«Совместимость»**: хорошие соседи и плохие соседи (по одной культуре через запятую или с новой строки).
7. Опубликуйте.

**Где появится:** страница растения по адресу `http://sadznaniy.local/rasteniya/<адрес>/`. Параметры и соседи выводятся блоками по стилю макета.

**Список растений** (админка → Растения) показывает колонки **Раздел** (таксономия), **Свет** и **Полив**.

<a id="разделы-и-типы"></a>
## 5. Разделы и типы растений

Это две таксономии каталога растений:

- **Раздел** — Сад / Огород / Цветы (админка → **Растения → Раздел**).
- **Тип** — Дерево / Кустарник / Многолетник / Однолетник / Овощ (админка → **Растения → Тип**).

Эти значения уже созданы при первом входе в админку. Их можно **переименовать, добавить или удалить** — так же, как рубрики записей.

Раздел можно использовать в меню: **Внешний вид → Меню → Растения → Раздел**.
Ссылки «Сад», «Огород», «Цветы» в блоке **«Разделы»** на главной ведут на архивы этих разделов.

<a id="популярное"></a>
## 6. Популярное на главной

Чипы «Популярное:» под первым экраном главной берутся из настроек темы.

1. Админка → **Внешний вид → Сад знаний**.
2. В списке **«Популярное на главной»** выберите растения (Ctrl — несколько).
3. **Сохранить изменения**.

Если ничего не выбрано — блок «Популярное» на главной просто не выводится. Порядок чипов — как в списке выбранных растений.

<a id="главная"></a>
## 7. Что и как показывается на главной

Главная собирается автоматически из вашего контента — редактировать код не нужно:

| Блок главной | Источник | Как наполнить |
|---|---|---|
| «Популярное» (чипы) | Настройки темы | Внешний вид → Сад знаний |
| «Блог и советы» | 2 последние записи | Записи → Добавить запись |
| «Календарь работ» | 3 ближайших события | События → Добавить событие |
| «Разделы» (Сад/Огород/Цветы/Рецепты) | Разделы растений и рубрика «Рецепты» | Растения → Раздел; Записи → Рубрики |

Если блок пуст (нет записей/событий) — он показывает подсказку, а не пустоту.

<a id="обновления"></a>
## 11. Обновления WordPress

- Админка → **Обновления**. Сначала обновите на копии LocalWP, проверьте сайт, затем на рабочем.
- Обновлять ядро/темы/плагины можно из админки. Тему **sad-znaniy** не обновляйте из репозитория WordPress — она своя.

## Быстрая проверка автономности (Этап 2)

Проделайте сами, без ИИ:

- [ ] Добавить событие → появилось в «Календаре работ» на главной.
- [ ] Добавить растение → открылась его страница с параметрами.
- [ ] Собрать статью из паттерна «Гайд по растению» → она в «Блоге и советах».
- [ ] Добавить запись в рубрику «Рецепты» → она в архиве «Рецепты».
- [ ] Выбрать растения в «Внешний вид → Сад знаний» → появились чипы «Популярное».

Если хоть одно действие требует правки кода — нужно доработать соответствующий раздел.
