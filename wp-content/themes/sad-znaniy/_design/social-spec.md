# Спецификация «Автопостинг и Дистрибуция» — Этап 8.5 (Партия 0)

Статус: **на утверждение владельцу**. Дата: 07.10.2026.
Документ — основа для Партий 1–4. До утверждения код не пишется.

## 0. Контекст и границы

- Этап выполняется **после переноса на хостинг** и включается той же ручкой, что и Метрика: константа `SZ_EXTERNAL_ON` в `wp-config.php`. На LocalWP всё строится и тестируется, реальная отправка включается только при `SZ_EXTERNAL_ON = true`. Это **второй внешний контур** проекта (первый — Метрика/Вебмастер в Этапе 8).
- Код — только в `includes/social/`, всё своё: без внешних SDK, без composer, без CDN. HTTP — через WP HTTP API (`wp_remote_post`).
- Данные — свои таблицы (`dbDelta` + версия миграции в опции) и опции. Никаких сторонних плагинов и новых CPT.
- Тексты — **анонсы собственных статей**: без «купи», без чужих и партнёрских ссылок. Информационный контент о собственном проекте — маркировка не требуется (см. вкладку «Маркировка»).
- Почему не плагин: код — часть темы, ноль зависимостей, единый стиль с SEO-Хабом и правило проекта «всё в теме». Модульная папка `includes/social/` при желании легко выделяется в плагин позже.

## 1. Матрица площадок

| Сеть | Ключ | Фаза | Доступ | Что нужно от владельца | Лимит текста | Фото |
|---|---|---|---|---|---|---|
| Telegram | `telegram` | 1 | Bot API: `sendMessage`, `sendPhoto` | бот в @BotFather + `chat_id` канала | 4096 | да (подпись ≤ 1024) |
| MAX | `max` | 1 | Bot API (аналог Telegram) | бот + `chat_id` | 4096 | да |
| ВКонтакте | `vk` | 1 | `wall.post`, `photos.getWallUploadServer` | ключ сообщества + `owner_id` | до 16 000 | да (`attachments`) |
| Одноклассники | `ok` | 2 | API «Медиа-топики» | ключ приложения + id группы | ~2000 | да |
| Pinterest | `pinterest` | 2 | API v5 (`pins`) | app token + `board_id` | заголовок 100 / описание 500 | да (обязательно) |

Фаза 1 — Telegram, MAX, VK. Фаза 2 (OK, Pinterest) — по той же модели, пишется после обкатки фазы 1.

## 2. Форматы постов

### Telegram / MAX

```
{emoji} {title}

{excerpt — 2–3 предложения, обрезка по границе предложения}

Читать полностью → {link}
```

Порядок: текст, затем ссылка. Если у статьи есть миниатюра — пост уходит через `sendPhoto` (картинка + подпись), ссылка остаётся в подписи. Inline-кнопка «🌐 Сайт» → статья. Хештеги в Telegram/MAX не добавляем (в тегах текста почти не работают).

### ВКонтакте

```
{title} {emoji}

{excerpt — до 200 символов, законченная мысль}

Полный разбор: {link}

{tags — 4–6 хештегов}
{question — опционально}
```

Порядок: текст → ссылка → хештеги → вопрос к читателям. Тон короче, эмодзи умеренно.

### Одноклассники (фаза 2)

Как VK, но тон теплее, обращение «уважаемые садоводы», ссылка отдельной строкой в конце.

### UTM-шаблон

`{link}?utm_source={network}&utm_medium=social&utm_campaign=auto`

Только для внутренней аналитики, на маркировку не влияет. Переходы видны в SEO-Хаб → «Эффективность».

### Хештеги

Собираются из меток записи автоматически: `#` + метка без пробелов. Нет меток — дефолтный набор из настроек (`#дача #сад #огород #советы`).

## 3. Расписание и очередь

- **3 слота в день**: 09:00 / 13:00 / 19:00 (настраиваются), часовой пояс — сайта.
- **Момент постановки**: публикация статьи → задание ставится в **ближайший слот ПОСЛЕ даты публикации статьи**. Статья опубликована в 10:30 → ближайший слот 13:00 того же дня; опубликована в 20:00 → 09:00 следующего дня.
- **Отложенные статьи** (дата публикации в будущем) → задание тоже на ближайший слот после этой даты (WP сам переводит запись в `publish` по расписанию, хук сработает тогда же).
- **Развод задач внутри слота**: если в один слот попали 3 статьи — они раскладываются по слотам с шагом (2-я → следующий слот, 3-я → через слот). Открытый вопрос №1 (см. §9).
- **Интервал между отправками** — 60 секунд (антиспам самих сетей).
- **WP-Cron каждые 5 минут**: выбирает задания со `status = pending` и `scheduled_at <= now`, отправляет по одной, пишет результат (`sent` / `error`, `attempts++`).
- **Повторы**: до 3 попыток с 60-секундным интервалом; после 3-й ошибки статус `error` + текст ошибки, дальше только вручную.

## 4. Модель данных

### Таблица `sz_social_queue` (миграция по опции `sz_social_db_version`)

| Поле | Тип | Смысл |
|---|---|---|
| `id` | bigint PK AI | |
| `post_id` | bigint | запись (`post`) или растение (`plant`) |
| `network` | varchar(20) | telegram / max / vk / ok / pinterest |
| `payload` | longtext | JSON: готовый текст, ссылка, теги, ссылка на картинку |
| `status` | varchar(20) | pending / sent / error / skip / manual |
| `attempts` | tinyint | число попыток |
| `scheduled_at` | datetime | когда отправлять |
| `posted_at` | datetime NULL | когда ушло |
| `error` | text | последняя ошибка |
| `erid` | varchar(80) NULL | задел под маркировку (фаза 2), сейчас пусто |
| `created` | datetime | когда создано |

Индексы: `(status, scheduled_at)` — выборка готовых; `(post_id, network)` — дедуп.

### Опции

- `sz_social_channels` (array) — вкл/выкл и секреты по сетям: `token`, `chat_id`/`owner_id`;
- `sz_social_templates` (array) — шаблоны текста для telegram / max / vk / ok;
- `sz_social_slots` (array) — 3 слота времени, лимит постов в день на сеть (дефолт 3), игнор-категории, дефолтные хештеги.

Секреты хранятся **только в опциях**; на экране маскируются (последние 4 символа), с кнопкой «показать».

### post_meta

- `_sz_social_posted` (array) — сети, куда запись уже ушла (дедуп);
- `_sz_social_question` (string) — «вопрос к читателям» для VK;
- `_sz_erid` (string) — задел под маркировку.

### Таблица `sz_aff_links` (фаза 1, задел под партнёрки)

| Поле | Тип |
|---|---|
| `id` | bigint PK AI |
| `slug` | varchar(60) UNIQUE |
| `store` | varchar(60) |
| `target_url` | text |
| `created` | datetime |

Плюс rewrite-правило `/go/{slug}/` → REST-редирект 302 с записью перехода. Создаём таблицу и правило **сразу** (хотя партнёрок ещё нет): когда владелец через полгода вставит первую партнёрскую ссылку, она будет считаться и управляться, а не потребует массовой замены по статьям.

## 5. Экран «📢 Дистрибуция»

Отдельный раздел меню админки (capability `manage_options`), 5 вкладок, единый стиль с SEO-Хабом.

### Вкладка 1 «Автопостинг» (строится целиком в Этапе 8.5)

- таблица очереди: статья, сеть, статус, когда, попытки, ошибка; фильтры по сети и статусу, поиск по статье;
- кнопки: «Повторить», «Отменить», «Отправить сейчас»;
- статистика за 30 дней: по сетям — отправлено / ошибок / переходов (из `utm_source` SEO-Хаба «Эффективность») + мини-график по дням на нативном canvas, без библиотек;
- последние ошибки с человеческим пояснением («Токен Telegram истёк — обновите во вкладке Настройки»).

### Вкладка 2 «Настройки каналов» (строится целиком)

- блок на каждую сеть: вкл/выкл, токены (маскированы + «показать»), `chat_id`/`owner_id`, кнопка **«Проверить связь»** — отправляет тестовый пост в канал и показывает зелёный/красный статус;
- шаблоны текстов с плейсхолдерами `{title} {excerpt} {link} {tags} {question}` + **живой предпросмотр** на реальном примере последней статьи;
- слоты времени (3 поля), лимит в день, игнор-категории.

### Вкладка 3 «Партнёрки» (заготовка, фаза 2)

- экран-описание будущих фич и чек-лист «что подготовить владельцу» (договоры с магазинами, регистрация в ОРД);
- контакт с БД уже сейчас: таблица `sz_aff_links` и редирект `/go/{slug}/` (см. §4).

### Вкладка 4 «Маркировка» (заготовка, фаза 2)

- памятка «Когда нужна маркировка»: анонс своей статьи — нет; партнёрская ссылка — да; свои платные услуги — спорно; РСЯ — маркирует сама система;
- чек-лист регистрации: самозанятый → «Мой налог» → ОРД (аккредитованные) → получение токенов;
- задел без будущей миграции: колонка `erid` в очереди и мета `_sz_erid` (заполняются позже).

### Вкладка 5 «Помощь» (Партия 4)

Аккордеон инструкций (дубль ADMINGUIDE + расширение): подключение Telegram за 5 минут (BotFather пошагово), подключение VK (ключ сообщества), подключение MAX, «Почему пост не ушёл: топ-5 причин», «Слоты и лимиты: как подобрать ритм», «Когда понадобится маркировка». Каждая инструкция — нумерованные шаги, «что вы увидите», «если что-то пошло не так».

## 6. Правила безопасности и антиспам

- **Запрет внешних ссылок**: если в тексте записи есть ссылка не на свой домен (`znai-sad.ru` / текущий домен) — задание НЕ ставится, получает статус `manual` («требует проверки владельцем»). Причина: до настройки маркировки через ОРД посты с партнёрскими ссылками публиковать нельзя.
- **Лимит постов в день на сеть** (по умолчанию 3, настраивается) — защита при массовом переносе/публикации черновиков.
- **Игнор-категории** — служебные страницы и рубрики из списка не анонсируются.
- **Дедуп**: `_sz_social_posted` по сетям. Повторное сохранение уже опубликованной статьи повторно НЕ постится.
- **Ручной репост**: чекбокс «Отправить в соцсети заново» в метабоксе + кнопка «Опубликовать в соцсети сейчас» с выбором сетей.
- **Проверка канала**: кнопка «Проверить связь» отправляет тестовый пост — чтобы понять, что дело в токене, а не в тексте.
