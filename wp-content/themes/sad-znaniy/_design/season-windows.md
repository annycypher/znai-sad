# Сезонные окна культур по регионам (Этап 5.7, контент)

Статус: **черновики созданы, ждут проверки фактов и публикации владельцем**.

Модель — основа для блока «Лунные дни для посадки» в карточке растения: окно = событие календаря
с типом работ «Посев»/«Посадка» и привязанной культурой (`_sz_event_crop`).

3. **Канон подзимнего посева** (в текстах событий и здесь): «Сеют по устойчивому похолоданию: днём стабильно ниже +5 °C, ночами земля схватывается. Календарные окна — ориентир, смотреть по погоде.»
4. **Косточковые в Сибири и на ДВ — осенние окна удалены**: вишня, черешня, слива, абрикос сажаются только весной (осенняя посадка вымерзает). Пометка добавлена в текст событий и выводится на карточке растения.
5. **Семечковые (яблоня, груша) Сибирь/ДВ — 10–30 сентября** (после начала листопада).
6. **Мелколуковичные** (крокус, нарцисс, гиацинт, мускари) — посадка: Юг 5–20.10, Средняя/Урал 10–25.09, Сибирь/ДВ 1–15.09. Карточек этих культур на сайте пока нет — события создадутся автоматически при появлении карточек (генератор ищет растения по названию).
7. **Укрытие роз** («Подготовка роз к зиме: укрытие», тип работ «Подготовка») — Средняя/Урал/Сибирь/ДВ 25.10–10.11, Юг 15–30.11. Это событие календаря, а не сезонное окно культуры.

Сроки считаются от устойчивых осенних заморозков региона: подзимний посев — по подмёрзшей, но не промёрзшей почве; озимые лук и чеснок — за 3–4 недели до устойчивых морозов; саженцы и многолетники — с запасом 3–4 недели на укоренение.

## Какие культуры получили сезонные окна

| Группа культур | Работы | Культуры |
|---|---|---|
| Подзимний посев | Посев | морковь, свёкла, петрушка, укроп, салат, шпинат, редис, дайкон, сельдерей, репа, редька |
| Озимые | Посадка | лук репчатый, чеснок |
| Осенняя посадка саженцев | Посадка | яблоня, груша, вишня, черешня, слива, абрикос, смородина, крыжовник, жимолость, голубика, облепиха, малина, ежевика |
| Осенняя посадка и деление | Посадка | роза, пион, тюльпан, лилейник, ирис, флокс, хоста, эхинацея, лаванда, клематис, гортензия (метельчатая и древовидная), хризантема |
| Клубника | Посадка | уже была (август, все регионы) — не дублировали |

Для каждой культуры создаётся по одному событию на климатическую группу; регионы внутри группы перечислены в одном событии.

## Как это работает

1. Блок в карточке растения берёт окна из `calendar_event` (посев/посадка) по культуре и региону из cookie.
2. Если месяц попадает в окно → показываются окно и лунные дни **только внутри окна**.
3. Если не попадает → «Сезон закрыт — вернётся в {месяц}» + благоприятные дни месяца со ссылкой на календарь.
4. Если для региона окон нет → честный дисклеймер, без выдуманных сроков.

## Публикация (владельцу)

Черновики лежат в **Календарь → Все события** (фильтр «Черновики»). Проверьте сроки по своему опыту и опубликуйте: выделить все → «Изменить» → «Опубликовать», либо попросить ИИ опубликовать пачкой.

## Проверка после публикации

1. `Календарь → Все события`: фильтр по культуре «Лук репчатый» → видны осенние окна по группам регионов.
2. Карточка растения с регионом Сибирь в октябре: лук — окно «Посадка озимого лука-севка»; морковь — «Сезон закрыт — вернётся в мае» (окно мая вне сезона).
3. Смена региона в шапке меняет окно без перезагрузки.
