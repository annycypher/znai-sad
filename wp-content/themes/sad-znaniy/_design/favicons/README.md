# Фавиконы «Сад знаний» — Этап 1 (локально, без выкладки)

Пять мастер-вариантов фавикона 512×512 из фирменного знака темы + превью.
На сайт ничего не подключено: `favicon.ico`, `site_icon` и `<link rel="icon">`
появятся только на Этапе 2, после выбора варианта.

## Что где лежит

```
_design/favicons/
  preview.html            ← открыть в браузере: все 4 варианта, 16/32/64/180, имитация вкладки
  variants/               ← мастеры 512×512
    v1.png                В1 «Полный логотип» (символ + САД ЗНАНИЙ), #20241F
    v2.png / v2.svg       В2 «Только символ», #20241F
    v3.png                В3 «Монограмма СЗ» на #68B96E, буквы #FFFFFF
    v4.png / v4.svg       В4 «Символ на тёмной плашке» #3A423B→#22271F, знак #68B96E
    v5.png / v5.svg       В5 «Белый символ на зелёной плашке» #68B96E, знак #FFFFFF
  preview/                ← уменьшения 16/32/64/180 px (Pillow, Lanczos)
  source/
    logo-sad.svg          ← очищенный вектор из assets/img/favicon.svg (viewBox 0 0 44.17 51.39)
    logo-sad-green.svg    ← тот же путь, заливка #68B96E (генерируется build.py)
    logo-sad-white.svg    ← тот же путь, заливка #FFFFFF (генерируется build.py)
  _tools/
    build.py              ← пересборка мастеров и уменьшений
    render/v1..v4.html    ← страницы 512×512, из которых снимается скриншот
    render/render.css     ← общие стили холста
    render/font.js        ← регистрация Golos Text (см. «Особенности»)
```

## Пересборка

```
cd "…\wp-content\themes\sad-znaniy\_design\favicons\_tools"
py build.py                # отрисовать всё заново
py build.py --no-render    # только проверка существующих мастеров и уменьшения
```

Скрипт печатает контрольную таблицу: размер, режим, альфу в четырёх углах,
bbox содержимого и поля.

## Инструменты и почему так

| Шаг | Чем сделано |
|---|---|
| Мастера 512×512 | Chrome (headless), `--device-scale-factor=1`, `--window-size=512,512`, `--default-background-color=00000000` (прозрачный фон), `--virtual-time-budget=5000` |
| Уменьшения 16/32/64/180 | Pillow 13, `Image.LANCZOS` |
| Векторные мастеры В2 и В4 | генерируются `build.py` из `source/logo-sad.svg` (чистый путь, без текста) |

ImageMagick в системе нет, у Local PHP отключено расширение `gd`, Pillow не читает
SVG и не грузит WOFF2 — поэтому мастера снимаются браузером. Страницы рендера
отдаются локальным сервером на `127.0.0.1` (его поднимает `build.py`): по `file://`
Chrome не применяет шрифты. В сеть ничего не уходит.

## Особенности и отклонения

1. **Шрифт.** Вордмарк В1 и монограмма В3 набраны фирменным Golos Text из
   `assets/fonts/*.woff2`. В headless-режиме `@font-face` из CSS остаётся в статусе
   `loading` (файл скачивается, но не применяется), поэтому `render/font.js`
   регистрирует шрифт через `FontFace` из `ArrayBuffer` и ставит
   `<html data-fonts="golos">`. Проверка:
   `chrome --headless=new --dump-dom http://127.0.0.1:<порт>/_design/favicons/_tools/render/v1.html`.
2. **SVG-мастера есть только у В2, В4 и В5.** В В1 и В3 текст остался бы зависимым от
   шрифта (standalone SVG не грузит внешние шрифты), поэтому для них мастер — PNG.
   Перевод текста в кривые — на Этапе 2, для выбранного варианта.
3. **Плашки В3/В4 — full-bleed** (на весь холст, скругление 112 px ≈ 22 %), а не с
   полями 10 %, как у символьных В1/В2: в 16 px поля «съедают» знак.
4. `_design/` лежит в репозитории темы, но на сервер выкладываются только файлы
   Этапа 2 — папка `_design/favicons/` на прод не попадает.

## Этап 2 — боевые иконки (вариант В5 утверждён)

```
assets/img/favicons/
  favicon.svg           2016 Б   вектор (Chrome/Edge выбирают его первым)
  favicon-32.png        1532 Б   32×32
  favicon-16.png         660 Б   16×16
  favicon.ico           4398 Б   16/32/48 в одном файле
  apple-touch-icon.png  6553 Б   180×180, без прозрачности (RGB), iOS сам скругляет

includes/favicons.php           печатает 5 <link> в wp_head (приоритет 2)
functions.php                   require_once includes/favicons.php
```

Пересборка боевых файлов (из мастера `variants/v5.png` и вектора `variants/v5.svg`):

```
cd "…\_design\favicons\_tools"
py build_prod.py
```

Скрипт печатает размеры файлов, кадры ICO и проверяет, что у apple-иконки нет альфы.
`?ver=<filemtime>` подставляет `sad_znaniy_asset_ver()` — иконки кешбастятся как CSS.

Замечание: WordPress сам отвечает на `/favicon.ico` картинкой-логотипом WordPress,
пока не задана опция «Иконка сайта». Браузеры это не использует (у нас есть
явные `<link>`), но если нужен «свой» `/favicon.ico` в корне — положить копию
`favicon.ico` в `public/favicon.ico` или задать иконку в админке.
