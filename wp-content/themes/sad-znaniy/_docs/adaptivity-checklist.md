# Чек-лист адаптивности и экспорта — планировщик участка (Этап 6, §8)

Проверяет владелец на локалке: http://sadznaniy.local/planirovshchik/ (план: 2-3 грядки с культурами, 1 дом, 1 дерево).
Отмечайте «ок» или замечание рядом с пунктом — правлю по списку.

## 1. Ширины экрана (DevTools → Responsive)

| Ширина | Что смотреть | Ожидаемый результат |
|---|---|---|
| **320 px** | тулбар, канвас, палитра | тулбар переносится без обрезки; палитра — выезжающая; канвас не меньше половины высоты; ничего не перекрывает кнопки |
| **390 px** | палитра элементов | 2 колонки, подписи читаются, тап-цели ≥ 44 px |
| **768 px** | переходный режим | панели выезжают, сводка и подсказки не наезжают друг на друга |
| **1024 px** | десктоп | левая палитра и правая панель видны постоянно, канвас по центру |
| **1440 px** | сетка и размеры | сетка 0,5 м читается, подписи размеров не выходят за края |
| **2560 px** | переполнение | канвас по центру, стеклянные панели не растягиваются на всю ширину |

## 2. Ориентация

- 390×844 (портрет) и 844×390 (ландшафт): при ландшафте нижний док занимает не больше четверти высоты, канвас пересчитывается без «залипания» зума.

## 3. Зум браузера

- Ctrl + «+» до **200%**: тулбар и панели рабочие, горизонтальной прокрутки страницы нет, кнопки не обрезаны, канвас остаётся в границах.

## 4. Тач и жесты (DevTools touch или телефон)

- Щипок — зум; один палец — панорама и перенос элементов; тап — выбор/размещение; углы участка тянутся; «Размеры» и «Отменить» доступны из дока; Alt-копия недоступна (есть «Дублировать»).

## 5. Экспорт

| Действие | Ожидаемый результат |
|---|---|
| «JPG» | скачивается `plan-{W}x{H}.jpg` — план, подписи, итог без пустых полей |
| «Печать/PDF» | диалог печати, 4 страницы A4 без обрезки, QR и ссылки читаемы |
| «Поделиться» (зелёная) | залогинен → ссылка `?plan=<uuid>`; гость → подсказка «Войдите» |
| «🗓 Календарь» (П5) | `znai-sad-plan-{8}.ics`, открывается в Google Calendar и iPhone |
| «✉ Отправить план» (П5) | письмо приходит получателю, ссылка ведёт на read-only план |

## 6. Данные, подсказки, кабинет

- pH: две грядки с разными требованиями рядом → жёлтая карточка + строка «Несовпадений почвы: N» в сводке.
- Совместимость: плохие/хорошие соседи в пределах 1 м → красная/зелёная карточка, не больше двух на элемент.
- «Мои планы»: список с датами, «Копировать», «Удалить» с подтверждением, «Создать новый план».
- Гость на PDF/ICS/«Отправить» → гейт входа; после входа действие продолжается.

## 7. Что мне сообщить

1. Номер пункта и что именно не так (лучше скриншот).
2. Устройство/браузер и ширину окна.
Я правлю и присылаю обновление с повторной проверкой.

# Чек-лист адаптивности — все страницы сайта (Этап 6/7, §8)

Разделы 1–7 выше — про планировщик. Ниже — тот же прогон для **остальных страниц**
и для двух новых сквозных элементов: постоянной панели слева (§9) и плиток
калькуляторов (§10). Порядок проверки одинаков: сначала ширины из §1, потом
ориентация, зум 200 %, тап-цели, печать.

## 8. Страницы: что и где смотреть

Локалка: `http://sadznaniy.local/<путь>/`. Проверяем на **320 / 390 / 768 / 1440 px**;
для каждой страницы — нет горизонтальной прокрутки, ничего не обрезано, тап-цели ≥ 44 px,
печать без потерь.

| Страница | Путь | Что смотреть | Ожидаемый результат |
|---|---|---|---|
| Главная | `/` | герой, плитки «Инструменты», длинные карточки | плитки в 1 колонку на 320–640 px, заголовки не рвутся по слогам, фоновые пятна не мешают читать |
| Лента статей | `/stati/` | карточки в сетке | 1 колонка на телефоне, 2–3 на 768/1440 px, даты и рубрики в одну строку |
| Статья | любая из `/stati/…` | типографика, таблицы, списки | таблицы прокручиваются внутри блока, не растягивают страницу; изображения во всю ширину |
| База растений (архив) | `/rasteniya/` | фильтры и карточки | фильтры переносятся, карточки в 1 колонку на 320 px |
| Карточка растения | `/rasteniya/<слаг>/` | таблицы «Полив/Свет/Почва», бейджи | подписи не выходят за карточку, бейджи переносятся |
| Календарь дачника | `/kalendar/` | сетка недель, выезжающие инструменты | нет горизонтальной прокрутки, панель инструментов не перекрывает сетку, зелёная ручка нажимается (≥ 44 px) |
| Лунный календарь | `/lunnyj-kalendar/` | месячная сетка, фазы | 7 колонок не сжимаются в кашу: на 320 px подписи сокращены, но читаемы |
| Планировщик | `/planirovshchik/` | см. §1–§6 | см. §1–§6 |
| Мои планы | `/moi-plany/` | список планов, кнопки | кнопки «Копировать/Удалить» не слипаются, подтверждение удаления доступно тапом |
| Калькуляторы (список) | `/kalkulyatory/` | плитки калькуляторов, блок «Смотрите также» | см. §10; «пилюли» переносятся строками, не обрезаются |
| Расчёт полива | `/kalkulyator-poliva/` | форма, результаты | поля в одну колонку, кнопка «Рассчитать» во всю ширину на 320 px |
| Удобрения | `/kalkulyator-udobreniy/` | форма, таблица доз | таблица прокручивается, итог читается без зума |
| Посев семян | `/kalkulyator-poseva/` | выбор региона и культуры | выпадающие списки не выходят за экран |
| Грунт и pH | `/kalkulyator-grunta-i-ph/` | форма, подсказки | подсказки не наезжают на поля |
| Уход за садом | `/uhod/` | разделы-карточки | карточки в 1 колонку на телефоне, заголовки целиком |
| Раздел ухода | `/uhod/<слаг>/` | список работ, ссылки на растения | ссылки ведут на карточки, длинные строки переносятся |
| Политика конфиденциальности | `/politika-konfidentsialnosti/` | длинный текст | ширина строки комфортная, нет прокрутки вбок |
| Страница 404 | любой неверный адрес | подсказка и ссылки | ссылки на главную и калькуляторы видны на 320 px |

## 9. Сквозная панель слева (новое, Этап 6/7)

Панель видна на **всех** страницах; выводится после `.frame`, поэтому фиксируется от окна.

| Проверка | Ожидаемый результат |
|---|---|
| Позиция | по центру левого края, не перекрывает текст статьи |
| Раскрытие | по наведению, по клику на ручку, по фокусу с клавиатуры; `Esc` закрывает |
| «Поделиться» | системное окно (телефон) или тост «✓ Ссылка скопирована» |
| «Мы в MAX», «Почта» | открываются в новой вкладке / почтовом клиенте |
| «Наверх» | активна после прокрутки > 400 px, плавно возвращает к началу |
| Мобильные ≤ 720 px | панель уходит в правый низ, кнопки вертикально, тап-цели ≥ 44 px |
| Зум 200 % | панель не наезжает на контент, текст кнопок не обрезан |
| Печать | панели и тоста на распечатке нет |

## 10. Плитки калькуляторов (новое, Этап 6/7)

| Проверка | Ожидаемый результат |
|---|---|
| 1440 / 768 px | сетка 2×2, иконки на эмеральдовой подложке, стрелка в правом нижнем углу плитки |
| 640 px и ниже | одна колонка, описания занимают не больше 3 строк |
| Зум 200 % | подписи не выходят за плитку, высота плиток растёт вместе с текстом |
| Клавиатура | `Tab` обходит 4 плитки и 4 «пилюли» «Смотрите также» по порядку, фокус виден |
| Печать | плитки печатаются как блоки со ссылками (URL читаемы) |

## 11. Что прислать владельцу по итогам прогона

1. Скриншоты: 320, 390, 768, 1440 px — по каждой странице из §8, где есть сомнение.
2. Отдельно: ландшафт 844×390, зум 200 %, предпросмотр печати (Ctrl+P).
3. Формулировка: страница + ширина + что не так («кнопка обрезана», «появилась прокрутка вбок»).
4. Заведите строку прямо в таблице §8 рядом с пунктом: «ок» или замечание — правлю по списку.

**Инструменты проверки** (без плагинов): DevTools → «Адаптивный режим» (ширина и ориентация),
Ctrl+P для печати, `Tab` для обхода фокуса, «Версия для слабовидящих» в футере для контраста.
