# Партия 5 (Этап 6, финал) — согласованный план и требования

Статус: план утверждён владельцем 15.10.2026, код — следующий заход. Все требования ниже — обязательные.

## 1. ICS из плана (анти-дублирование)

- Маршрут: `?plan=<uuid>&ics=1` на странице планировщика (по образцу `sad_znaniy_ical_maybe_output()` из `includes/ical.php`).
- **Гейт:** только залогиненным (как у PDF). Гостю — гейт `#plnGate`.
- **События — на УНИКАЛЬНЫЕ КУЛЬТУРЫ плана, по одному на культуру** (не на каждый элемент). В `DESCRIPTION` — «элементов в плане: N».
- Заголовок события: «Посадка: {культура}»; в описании: ссылка на карточку растения + ссылка на read-only план.
- **Даты:** берём сезонное окно из `calendar_event` для региона пользователя, если окно есть; если нет — событие без даты в первом месяце плана с пометкой «срок уточните в карточке».
- Файл: `znai-sad-plan-{uuid8}.ics`, `Content-Type: text/calendar`, `Content-Disposition: attachment`.
- Переиспользуем: `sad_znaniy_ical_escape()`, `sad_znaniy_ical_fold()`, `sad_znaniy_ical_vevent()`, шаблон заголовков из `sad_znaniy_ical_maybe_output()`.
- Модуль: `includes/planner-ics.php` (CLI-guard не нужен — это веб-функция, не `_tools`).
- ADMINGUIDE: как пользователь подписывается на план (добавить .ics в Google Calendar / iPhone).

## 2. Отправка плана письмом

- Кнопка **«✉ Отправить план»** рядом с экспортом; форма: email получателя + необязательное сообщение.
- **Валидация:** `is_email()` плюс **запрет отправки на адрес самого сайта** (самоспам-защита).
- **Лимит: 10 писем в час на пользователя**, значение редактируемое (настройка/фильтр `sad_znaniy_planner_mail_limit`), при превышении REST отвечает вежливым текстом с указанием лимита.
- Транспорт: REST `POST /sad-znaniy/v1/plans/mail` — только залогиненным, `X-WP-Nonce`, владелец плана.
- Содержание письма: read-only ссылка `?plan=<uuid>`, размер участка, список культур.
- Проверка на локалке: письмо появляется в «🛡 Безопасность → Почта (локалка)», ссылка внутри корректна.
- Модуль: `includes/planner-mail.php`.
